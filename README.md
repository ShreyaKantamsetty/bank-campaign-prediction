# Bank Marketing ML Superset

DJS Compute AIML mentee assignment — supervised (Task 1) + unsupervised (Task 2) ML on the UCI Bank Marketing dataset.

## Dataset

Download `bank-additional-full.csv` from: https://archive.ics.uci.edu/dataset/222/bank
Place it in a `data/` folder before running the notebook.

## Structure

- `notebooks/` — Colab notebooks (Task 1 + Task 2)
- `evidence-pack/` — decision documentation
- `memo/` — final decision memo
- `outputs/` — top-500 table, plots
